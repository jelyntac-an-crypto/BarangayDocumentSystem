## Information the portal collects

When you register or use the portal, it may process:

- Account details: resident ID number, username, email address, and password credential.
- Profile information: name, birth date, age, sex, contact number, address, ZIP code, and civil status.
- National ID number, which this application stores encrypted in the database.
- Security-question answers, stored as password hashes for account recovery.
- Document request details, uploaded supporting files, request status, staff remarks, and notifications associated with your request.
- Security and service records such as login/OTP attempts, CAPTCHA failures, IP address, browser user-agent, timestamps, and security events.

Passwords, security answers, and OTP codes are not stored as readable values; the application stores password hashes for verification. The system also records the time you accept the privacy consent during registration.

## Why information is used

Information is used to create and verify accounts, secure sign-in and account recovery, confirm eligibility and identity for requested documents, process requests, contact you about verification or request status, provide notifications, prevent abuse, and investigate security events.

The Barangay must confirm the applicable lawful basis for each processing purpose and whether any information is required by law or office policy. Consent to this notice should not be described as the sole lawful basis for every purpose without that review.

## Storage, security, and retention

The application uses password hashing for account credentials, security answers, and OTPs, encrypts the national ID number in the database, and maintains access and security event records. These technical controls reduce risk but cannot guarantee that unauthorized access will never occur. The Barangay is responsible for access control, backups, server security, incident handling, and proper disposal.

Personal information should be kept only for as long as necessary for the stated purposes or as required by applicable law and the Barangay's approved records schedule. The system owner has not supplied an approved retention period, so this notice does not invent one.
